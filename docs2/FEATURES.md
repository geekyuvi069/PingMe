# PingMe — Features

## 1. Pinging System

- Pings every 15 minutes (interval customizable from settings)
- Chrome extension shows countdown timer and fires browser notification
- Free text response — type naturally, no categories or dropdowns
- Ignored pings automatically logged as "untracked"
- Sleep window silences all pings during set hours (e.g. 2AM–10AM)

---

## 2. Chrome Extension

A persistent browser extension handles all active tracking.

**Header:** Countdown timer showing time until next ping. Badge on extension icon mirrors this.

**Main panel actions:**

| Action | What happens |
|---|---|
| Log It | Submits activity log, resets timer |
| Skip | Logs ping as skipped/untracked |
| Note | Saves typed text as a quick note |
| Agenda | Expands agenda panel inline |

**Reading tab** (new):
- Book switcher — up to 3 active books
- Snippet display (~280 words, ~2 min read) with estimated read time
- Done / Read More buttons
- Progress bar: `34% · Snippet 34/142 · ~18 days to finish`
- Daily pip tracker — 2 dots that fill as you complete daily reads
- Nudge banner on main panel if you haven't read today

**Sleep mode:** Manual sleep toggle silences pings and shows a rotating motivational line in place of the countdown.

---

## 3. Sleep Window

- Set a start and end time during which all pings are silenced
- Configured from the web dashboard settings page
- Example: 2:00 AM to 10:00 AM
- During this window: no popup, no badge alert
- Morning kickoff message sent automatically when sleep window ends

---

## 4. Pause / Resume

- Pause temporarily stops pings without touching your sleep window
- Optional duration stored in settings (`pauseUntil`)
- Auto-resumes after duration expires on next ping trigger
- Pause state stored in MongoDB so it persists across restarts

---

## 5. Sticky Notes

A scratchpad for thoughts you don't want to lose.

- Capture from extension — Note button
- Capture from web dashboard — notes panel input
- Notes are timestamped, saved separately from logs and agenda
- Notes appear in your end of day summary and daily email
- **Notes are not tasks** — unstructured captures, no checkboxes, no carry-forward

---

## 6. Agenda

Your daily committed task list.

- Add from extension agenda panel or web dashboard
- Each item has a checkbox — click to mark complete
- **Incomplete items auto carry forward to the next day**
- Carried-forward items flagged with `carriedFrom` date
- Appears in morning kickoff message every day
- Completion recap in end of day summary

---

## 7. Web Dashboard

A simple dark-themed web interface served by FastAPI.

**Pages:**

- **Dashboard (`/`)** — three-column layout:
  - Left: today's timeline — all log entries with timestamp, response, and category badge
  - Middle: agenda panel with checkboxes, add new item input
  - Right: notes panel with timestamps, add new note input
- **Settings (`/settings`)** — form to update sleep window, ping interval, summary time, email, timezone

No React. No npm. Pure HTML + Jinja2 templates + vanilla JS.

---

## 8. Auto-Categorization

### Phase 1 — Keyword Matching (active, zero cost)
Keyword matching on free-text responses automatically assigns a category to each log entry.

| Category | Example responses |
|---|---|
| `deep_work` | "studying RAG", "reading paper", "writing code", "building feature" |
| `break` | "making tea", "lunch", "taking a walk", "resting" |
| `meetings` | "on a call", "team sync", "discussion", "interview" |
| `admin` | "checking email", "replying messages", "planning", "reviewing" |
| `distracted` | "scrolling", "YouTube", "random browsing", "social media" |

### Phase 2 — Gemini-Powered Categorization (active)
`categorize_with_ai()` in `services/ai.py` sends the response to `gemini-2.0-flash-lite` for smarter classification. Catches edge cases keyword matching misses:
- "watching a tutorial on transformers" → `deep_work`
- "quick standup on Teams" → `meetings`
- "responded to the client about the invoice" → `admin`

Falls back silently to keyword matching if Gemini fails. Zero user-visible impact on failure.

## 9. AI Mid-Day Nudge

Every time the extension popup opens, a single sharp sentence appears above the log input. Generated by Gemini based on today's logs so far.

- Only shown if ≥3 logs exist today
- Hard 4-second timeout — popup never waits for it
- Uses `gemini-2.0-flash-lite` (fastest, cheapest)
- Silently hidden if API unreachable or not enough data

Examples:
- "3 hours of admin — deep work window is closing fast."
- "4 skips in a row — what's actually blocking you?"
- "Solid focus since 9am, protect this streak."

---

## 10. End of Day Summary

Sent automatically at your chosen time via **Email**.

**Email contains:**
- Hero stat cards (deep work time, total pings, agenda completion)
- Category breakdown with gradient progress bars
- **AI Insight** — 4–6 sentence Gemini paragraph referencing your actual logged activities
- Full time log table with category badges
- Agenda recap (completed ✅ vs incomplete ⏳)
- Notes captured during the day
- **Reading section** — snippets read, words read, per-book progress bars, estimated finish date
- Tomorrow's priority list from incomplete agenda items

**Email subject line:**
```
PingMe 2026-03-18 | Study: 2h 30m | 📖 3 snippets | 3/5 done
```

## 11. Morning Kickoff Message

Sent via Telegram when your sleep window ends every day.

**Contains:**
- Good morning greeting
- Today's full agenda — yesterday's incomplete items already merged in and flagged

## 12. Daily Reading Habit

A lightweight reading system built into PingMe.

### How it works
- Upload a PDF book or search Open Library by title
- PingMe splits the book into ~280-word snippets (~2 min each)
- Two snippets served per day (morning + evening nudges via extension)
- Reading activity tracked in `reading_logs`, never wiped

### Book management
- Up to 3 books active simultaneously
- Round-robin snippet serving across active books
- "Read More" button for bonus snippets beyond the daily 2
- Per-book progress: current snippet, total snippets, % complete, days-to-finish estimate

### Days-to-finish formula
```
remaining = totalSnippets - currentSnippet
avg_daily = snippets read in last 7 days / 7
days_to_finish = remaining / avg_daily  (if avg > 0)
```

### Reading nudges
- Extension badge + nudge banner on main panel if you haven't hit your 2 daily snippets
- Morning alarm at 9AM, evening alarm at 7PM

### Reading in the daily email
```
📖 Reading Today
Atomic Habits    ████████░░  34%  (+2 snippets · ~560 words)
                 At this pace: ~18 days to finish
Sapiens          ███░░░░░░░  12%  (+1 snippet · ~280 words)
Total: 3 snippets · 840 words · 🔥 7-day streak
```

## 13. Weekly Rollup

Every Sunday a weekly snapshot is saved and a weekly email is sent.

**Weekly email contains:**
- **AI Weekly Insight** — 3–5 sentence Gemini paragraph on the week's patterns, specific days, and one concrete change to make next week
- Time breakdown bar chart across all categories
- Daily deep work breakdown (Mon–Sun)
- Top activities across the week
- Most and least productive days
- **Reading section** — total snippets/words for the week, per-book progress delta, best reading day, streak

**Storage:** Weekly snapshots are permanent and never deleted. Daily snapshots are deleted after rollup.
